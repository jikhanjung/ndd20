# 20260907-003 · 문서를 코드에 맞추고, 제 venv 를 세우다

## 왜 어긋나 있었나

앞 판(`002`)이 *"정적 HTML 한 장이면 된다"* 를 걷고 Django 화면을 세웠는데,
**그 판단이 커밋 메시지에만 남고 `CLAUDE.md`·`HANDOFF.md` 로 안 올라갔다.**
그래서 세 곳이 서로 다른 말을 하고 있었다 — 지침은 "Django 를 안 쓴다" 인데
저장소에는 `manage.py` 가 있는 꼴이다. `devlog/` 도 규약과 달리 비어 있었다.

**걷은 판단은 지우지 않고 "걷은 것" 절로 남겼다.** 지워 버리면 다음에 같은
자리에서 같은 잘못을 되풀이하고, 그때 왜 걷었는지가 안 보인다.

## 고친 것

- `CLAUDE.md` — *왜 Django 가 아닌가* → ***Django 는 보는 화면에만 쓴다*.**
  가르는 선은 **서버냐 아니냐가 아니라 받느냐 안 받느냐**라고 다시 적었다.
  구조 절에 `viewer/`·`docs/`·`out/`·`requirements.txt` 를 넣었다
- `HANDOFF.md` — 화면을 *지금 있는 것* 에 올리고, 자료를 열어 정한 규칙 둘
  (**틈>0.1 인 3% 를 가른다** · **밑동은 따로 찾는다**)을 요약해 붙였다
- `TODOs.md` — 첫 항목의 *정적 HTML 로 본다* 를 걷었다. **보는 자리는 이미
  있으니 얹는다**, 다만 **성적은 명령이 파일로 떨군다**
- `devlog/` — `001`·`002` 를 소급해 남겼다
- `viewer/views.py` — 크롭이 `out/crops/` 에 쌓인다고 적혀 있었다. 실제 자리는
  `out/thumbs/` 다

## 정적을 걷으며 **정말 잃은 것 하나**

정적 쪽 논거였던 *"뽑아 둔 장이 그 판의 기록으로 남는다"* 는 살아 있는 화면에
없다. 화면은 다음 판이 오면 덮인다. 그래서 규칙을 하나 세웠다 —
**기록은 화면이 아니라 명령이 파일로 떨군 것이고, 성적을 화면에서 읽어 옮겨
적지 않는다.**

## 제 venv 를 세웠다

문서가 `python manage.py runserver` 라고만 적어 두었는데, **맨 `python3` 에는
django 가 없어 실제로는 형제 저장소의 venv 로 돌고 있었다.** 읽기만 하니 저쪽이
흔들리지는 않지만 **저쪽이 판올림하면 이쪽이 조용히 딸려 간다** — `CLAUDE.md`
의 *간섭을 피한다* 와 어긋나는 자리다.

`~/venv/ndd20` (python 3.12 · django 5.2 · pillow 12.3) 과 `requirements.txt` 를
두고 끊었다. **명령도 화면도 같은 것으로 돈다.** numpy·opencv 는 **아직 안
적었다** — 폴리라인을 채울 때 들어오고, 그때 무엇 때문에 들어왔는지와 함께 적는다.
